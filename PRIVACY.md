# Privacy

PCDeck is designed to be local-first.

- Pairing, layouts, trusted devices, workflows, and snapshots are stored locally.
- NeuralDeck learning is local and opt-in.
- PCDeck does not require a cloud account for core LAN control.
- Motion/gyro data used by tablet controls is processed for the requested control behavior and is not intended as analytics data.
- The public repository contains demo configuration only; personal profiles and trusted-device records are excluded.

Before a commercial release, this document should be reviewed and expanded to match the final telemetry, licensing, update, and payment implementation.
